# Linear Search in Python

This Python program checks whether a target element exists in a list using a simple linear search method.

Explanation
A list of numbers is stored in nums
target contains the value to search
The loop checks each element one by one
If the target is found:
"Found" is printed
break stops the loop
If the loop finishes without finding the target:
"Not Found" is printed using the else block.

Python Lists
